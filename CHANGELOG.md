# История изменений

## [Не выпущено]

### Добавлено
- Поддержка загрузки нескольких документов одновременно
- Сортировка в списке документов
- Docker: многоступенчатая сборка (multi-stage build) для бэкенда и фронтенда
- docker-compose.yml с health-check для обоих сервисов
- Makefile для типовых Docker-операций
- Установка CPU-версии PyTorch без CUDA-зависимостей
- Оценки схожести (similarity scores) в результатах поиска
- Цветовые индикаторы релевантности (зелёный / оранжевый / серый)
- Эндпоинт `DELETE /documents/{doc_id}` для удаления документа и его эмбеддингов

### Изменено
- ML-модель заменена с `paraphrase-multilingual-mpnet-base-v2` на `all-MiniLM-L6-v2`:
  - Размер загрузки: 1,5 ГБ → 90 МБ (в 16 раз меньше)
  - Скорость инференса: в 3–5 раз быстрее на CPU
- Хранилище эмбеддингов переработано: теперь используется **чанковая** схема (`chunks` table) вместо единого вектора на документ — это позволяет искать по частям больших документов
- API поиска возвращает `similarity_score`, `chunk_text`, `chunk_index`
- Конфигурация вынесена в pydantic-settings (`app/core/config.py`)
- Тома Docker переименованы: данные → `./data`, кэш модели → `./model-cache`

### Исправлено
- Удалены CUDA-зависимости из `requirements.txt`
- URL бэкенда на фронтенде теперь настраивается через `REACT_APP_API_URL`
- Исправлено расположение томов в docker-compose.yml

## [0.1.0] — Первый релиз

### Добавлено

**Бэкенд:**
- FastAPI-сервер с документацией OpenAPI (Swagger UI + ReDoc)
- Фабрика приложения (`create_app`) для изолированного тестирования
- Модульная архитектура: routes, services, ml, models, core
- `DatabaseManager` — репозиторий для SQLite (паттерн Repository)
- `DocumentParserService` — парсер с поддержкой стратегий (PDF, DOCX, TXT, JSON, XML, HTML, CSV)
- `EmbeddingService` — генерация эмбеддингов через sentence-transformers
- `EmbeddingDatabase` — SQLite-хранилище векторных чанков
- `TextPreprocessor` — нормализация Unicode, очистка HTML, усечение до 10 000 символов
- `ModelRegistry` — singleton-менеджер жизненного цикла модели
- Автогенерация эмбеддингов при загрузке документа
- Семантический поиск с косинусным сходством
- Деградация: при недоступности ML поиск переключается на поиск по имени файла

**Фронтенд:**
- React 19, современный адаптивный интерфейс
- Тёмная тема
- Голосовой поиск (русский язык)
- Модальное окно предпросмотра документа
- История поиска
- Список документов с сортировкой

**Инфраструктура:**
- Python 3.12
- Две базы данных SQLite: `docstore.db` (документы) и `embeddings.db` (эмбеддинги)
- Docker + Docker Compose
